❌ Why it says "Not Allowed"

Discord won't let you use their own ToS link (https://discord.com/terms) as your app's Terms of Service URL. They require your own unique page hosted on a domain you control.

✅ What you need to do

Option 1 — Leave it blank (easiest)

  • If your bot is not verified yet (under 75 servers), this field is optional
  • Just delete the URL → leave it empty → Save Changes
  • Same for Privacy Policy URL — you can leave both blank until you need them

Option 2 — Make your own simple page

Create a free page using GitHub Pages, Netlify, or Replit with something like:

Here's the step‑by‑step, click‑by‑click to make and host those pages — super easy, no coding experience needed!

✅ Method 1: GitHub Pages (Best & Free)

This gives you a permanent link like yourname.github.io/canstizz/tos.html

Step 1 — Make the files

  1. On your computer → create a new folder → name it canstizz-bot-pages
  2. Open Notepad (Windows) or TextEdit (Mac)
  3. Copy the full TOS code I gave you → paste it into the blank document
  4. Click File → Save As
    • File name: tos.html
    • Save as type: All Files
    • Encoding: UTF‑8
    • Save it into your folder
  5. Repeat for the Privacy Policy code → save as privacy.html
✅ You now have two files in your folder:
  • tos.html
  • privacy.html

Step 2 — Upload to GitHub

  1. Go to https://github.com → sign up / log in
  2. Click + → New Repository
    • Name: canstizz-bot-pages
    • Set to Public
    • Tick Add a README file
    • Click Create Repository
  3. Click uploading an existing file → drag your tos.html and privacy.html files into the window → click Commit changes

Step 3 — Turn on GitHub Pages

  1. Go to Settings (tab at the top of your repo)
  2. Scroll down to Pages (left sidebar)
  3. Under Source, change from "None" to main → click Save
  4. Wait ~1 minute → refresh the page
  5. You'll see:
    Your site is live at: https://your-username.github.io/canstizz-bot-pages/

Step 4 — Get your links

  • Terms of Service → https://your-username.github.io/canstizz-bot-pages/tos.html
  • Privacy Policy → https://your-username.github.io/canstizz-bot-pages/privacy.html

Step 5 — Paste into Developer Portal

  • Go to https://discord.com/developers/applications → your app
  • Paste those two links into the correct fields → Save Changes ✅

✅ Method 2: Replit (Even Faster)

  1. Go to https://replit.com → sign up / log in
  2. Click + Create → choose HTML/CSS/JS → name it canstizz-pages
  3. Delete all the code in the index.html file
  4. Paste the TOS code I gave you → click Run ▶️
  5. A preview appears → click the Open in new tab icon → copy that URL
  6. Add a new file named privacy.html → paste the privacy code → save
  7. Your links look like:
    • https://canstizz-pages.your-username.repl.co/tos.html
    • https://canstizz-pages.your-username.repl.co/privacy.html
  8. Paste those into Discord Developer Portal → Save ✅

⚠️ Important Checks

  • Your link must start with https:// — not http://
  • When you click the link, the page must load without needing to log in
  • If it still says "Not Allowed":
    • Double‑check you didn't paste discord.com links — use YOUR new link
    • Make sure the domain is yours (github.io, repl.co, etc.)

Which one should I use?

  • GitHub Pages → better long‑term, cleaner link, won't go to sleep
  • Replit → faster to set up right now
